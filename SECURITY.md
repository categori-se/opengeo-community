# Security

This is an early community source edition. The local development environment uses
synthetic authentication and local object/queue substitutes. Bind it to loopback;
do not expose that environment to a network or use it for confidential production
data. A supported production deployment remains on the roadmap.

For a vulnerability, contact the maintainer privately at `2301690+aaronkyle@users.noreply.github.com`.
Include affected versions, reproduction steps and impact. Do not put credentials,
private data or exploit details for an unpatched issue in a public issue.

Response times are not guaranteed. Security fixes for the community
application remain public; a subscription is not required to receive them.
