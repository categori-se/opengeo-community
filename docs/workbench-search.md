# Search in OpenGeo Studio

- Loaded feature search: type at least two characters in Search to inspect matches from the active Project's loaded features, including loaded KML attributes. Exact displayed names rank before name prefixes, name substrings and other attributes; ties retain Layer and feature order. Search shows six results with the total match count and explains the ranking. Each result displays its Layer, retained dataset/version/source-revision identities and match reason; unavailable identities are disclosed. Choose a result to select its exact Layer/feature and navigate. No other Project, remote index or unloaded source is searched. This addition is locally verified and not yet deployed.

- Coordinate navigation: open Search features, coordinates or Plus Codes in the Layers panel, enter WGS84 latitude, longitude in decimal degrees or a full Plus Code such as `8FVC9G8F+6W`, and choose Go to coordinate or press Enter. Typing only searches loaded feature attributes. Full Plus Codes decode offline to their exact WGS84 cell; Search fits that cell and displays its angular size and Open Location Code provenance. For a short code such as `9G8F+6W`, expand Reference for short Plus Codes and choose Use map center as reference near the intended place. Later map movements preserve that captured reference; Clear reference removes it. Recovery reports the full code and exact reference used. It never infers a locality from text. Invalid input or a missing reference keeps the current view and focuses the field for correction. Earth maps accept longitude from -180 to 180 and cell centers within the renderer's -85.05112878 to 85.05112878 latitude range; coarse cells are visibly clipped to that range. Polar navigation, global place/address lookup and searching named views remain unsupported. Navigation uses the normal camera captured by Project Save; the temporary reference and query are not saved. Full/short Plus Code navigation is locally verified and not yet deployed.
