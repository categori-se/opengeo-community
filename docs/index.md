# Documentation

Choose a guide for your task. Start with [deployment choices](community-deployments.md)
if you are deciding between the Demo, hosted Studio and your own installation.

## Use Studio

- [Workflow guide](community-workflow.md): curate sources, reuse Layers, compose
  Projects and carry results into a later study.
- [Example studies](community-examples.md): try a small exercise with stated
  inputs, rights and expected results.
- [Workbench](workbench.md): find the map, Layer and data controls.
- [Processing](user-guide/processing.md): choose browser tools or deliberate
  server jobs and review their results.
- [Print Studio](print-studio.md): compose maps and other content on a page and
  export supported outputs.
- [Rendering engines](community-renderers.md): choose a renderer and understand
  differences in supported content.

## Install and operate

- [Choose an installation](community-deployments.md): compare environments,
  configuration and operator responsibilities.
- [Run locally on Linux](community-development.md): install dependencies, start
  the connected stack, save work and reopen it.
- [Deploy in your AWS account](community-aws.md): configure identity, storage,
  processing and releases.
- [Support](../SUPPORT.md): report an installation problem or discuss assistance.
- [Security](../SECURITY.md): report a vulnerability through the appropriate channel.

## Develop

- [Contributing](../CONTRIBUTING.md): choose a focused task and prepare a reviewable
  contribution.
- [Architecture](community-architecture.md): understand the application and service
  boundaries.
- [Local development](community-development.md): run and update persistent local
  services and use the optional test profiles.
- [Analysis console](python-automation.md): work with browser JavaScript and
  configured local Python, JavaScript or Bash profiles.
- [API documentation](api/README.md): find maintained service contracts and examples.

## Reference

- [Capabilities and limits](community-capabilities.md): check implemented workflows
  and the scope of their acceptance.
- [Data interfaces](community-interoperability.md): review supported formats,
  services and exchange boundaries.
- [Reference applications](reference-applications.md): understand comparisons and
  their declared scope.
- [Licensing](community-licensing.md) and [open-source foundations](open-source-foundations.md):
  distinguish software terms, attribution and data/service rights.
- [Acknowledgements](../ACKNOWLEDGEMENTS.md): find upstream projects and credits.
- [Release record](../COMMUNITY-RELEASE.json): inspect the detailed source and
  validation record.
