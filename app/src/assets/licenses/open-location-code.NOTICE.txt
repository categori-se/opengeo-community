OpenGeo source and modifications:
app/src/lib/plusCode.js is an independently written integer-cell implementation
of the published Open Location Code standard. Its short-code recovery adapts the
reference recoverNearest algorithm, including strict half-cell comparisons,
latitude pole guards, longitude normalization, and recovery re-encoding.
OpenGeo adds bounded strict input validation and an explicit reference-location
contract. The upstream JavaScript implementation is not packaged as a dependency.

app/test/plus-code.test.mjs includes numeric subsets from the upstream decoding
and short-code recovery fixtures: 13 decoding rows and 17 recovery rows. All
embedded fields match the pinned official fixtures exactly; the remaining local
boundary and invalid-input cases are OpenGeo additions. The upstream CSV files
have no separate copyright or license header; the retained repository LICENSE
applies to this source record.
